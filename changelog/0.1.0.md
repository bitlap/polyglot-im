## HTTP 路由与响应约定

- http4s Router 统一挂载 /api/v1/im，业务路由不重复声明公共前缀，探针保持根路径。
- HTTP 成功统一为 code=200、message=success、data；失败保留 HTTP 状态，数字 code 与 error_code 业务码分开，探针、404 和过载响应保持同一结构。
- Scala、Python、Dart/Flutter SDK 自动解包并兼容旧响应；更新基准客户端、OpenAPI、共享 Schema/样例、三端契约测试与集成文档，WS 帧保持原样。
