# Polyglot IM 0.1.1

## 项目与构建

- 压测支持完整矩阵报告与单/四进程发压诊断，分别核验服务源码、原始样本和资源预算；WS 超时保存失败计数并继续后续轮次，保留预热与连接错误；修正已退出进程组的权限探测误报。

- 长时间压测每轮完成后原子保存结果，支持 .json.gz 输出与报告读取；中断时保留已完成轮次，以实际覆盖区分完整矩阵和部分测量。

- 完成七场景、单/双实例、四档并发、三轮重复共 168 轮压测，保留 32 条 WS 未确认投递及共享主机干扰；补充写入与历史读取的 12 轮发压进程诊断。README 展开全部 56 个测试单元的结论，逐轮详情、数据库 CPU/I/O/WAL 与等待、原始数据及异常日志可复核。测量服务基线为 0.1.0 对应历史源码，不宣称已测得后续业务版本容量。

- 新增本机 Scala Client 发布入口，统一版本 0.1.1；远程发布继续禁止。

## scala-client

- 提供固定版本本地 Ivy 依赖，验证作者审核消息共享契约。

## scala-server

- WebSocket 帧回归测试显式管理执行线程池与连接，兼容 JDK 17 的 HttpClient，不依赖 JDK 21 的 AutoCloseable 接口。

- http4s 从 0.23.30 升级到 0.23.38，修复自动 Pong 与数据帧并发写入可能交错的问题；新增真实 TCP 并发心跳/文本回归测试。

- 支持 open_user / open_review 受控动作及 APNs 通知分组。

## dart-client

- 提供显式停止前台兜底轮询，增加审核消息往返契约。

## flutter-client

- 通知列表统一卡片与未读圆点，信箱图标和标题同一行居中，正文及分钟时间与卡片左边缘对齐；增加布局对齐断言。

- 前台系统通知按账号显式配置；消息卡片支持关闭点击累计已读，后台停止轮询。

## python-client

- 增加审核消息共享契约，未知 payload 向前兼容。

## benchmark

- WS 接收协程异常不再被丢弃或统一归为末尾超时；及时停止失效连接发压，保留关闭码、原始异常类型、心跳超时标记与逐连接未确认计数，预热诊断同样保存。
- 增加同用户、同设备、同总并发的单/四进程 WS 对照及加速 Ping 专项入口；集中采样数据库，保留子进程统计和退出码。专项报告记录复现、函数剖析、故障注入与依赖升级对照，历史失败不覆盖。

## 用户会话与 uni-app

- Server 提供 UserAuthenticator 用户鉴权端口及默认固定 HTTP 内省适配器，启用后关闭本地用户 JWT，生产者权限仍独立校验。
- 增加 uni-app 本地 npm 包，默认 uni.request、账号隔离持久化、落盘后 ack、前台轮询与退避、历史及已读。统一 VERSION 同时管理该包。

## uniapp-client

- 补齐单聊、会话/历史分页、阅读回执、独立未读、设备 token 和推送偏好。
- 增加短期 ticket WebSocket、串行落盘后确认、有界帧队列、断线补拉和前后台暂停恢复。
- 导出 HttpApi、SyncClient、NotificationSender、RetryPolicy 和领域校验；提供 HTTP/Socket/存储/codec/凭证端口。并发鉴权刷新、有限瞬时错误重试、请求体冻结、中止和资源所有权覆盖默认适配器。
- 去掉通知缓存 500 条静默截断；明确 uni 存储配额失败不 ack、平台 UI/APNs 与可信 Outbox 的边界。
- 增加 npm tgz 独立安装与真实 HTTP/WS 验收，接入跨语言集成 CI；统一补充当前功能和技术设计文档。
