# Polyglot IM 0.1.1

## 项目与构建

- 新增本机 Scala Client 发布入口，统一版本 0.1.1；远程发布继续禁止。

## scala-client

- 提供固定版本本地 Ivy 依赖，验证作者审核消息共享契约。

## scala-server

- 支持 open_user / open_review 受控动作及 APNs 通知分组。

## dart-client

- 提供显式停止前台兜底轮询，增加审核消息往返契约。

## flutter-client

- 通知列表统一卡片与未读圆点，信箱图标和标题同一行居中，正文及分钟时间与卡片左边缘对齐；增加布局对齐断言。

- 前台系统通知按账号显式配置；消息卡片支持关闭点击累计已读，后台停止轮询。

## python-client

- 增加审核消息共享契约，未知 payload 向前兼容。

## benchmark

- 无行为变更，使用统一版本。

## 用户会话与 uni-app

- Server 提供 UserAuthenticator 用户鉴权端口及默认固定 HTTP 内省适配器，启用后关闭本地用户 JWT，生产者权限仍独立校验。
- 增加 uni-app 本地 npm 包，默认 uni.request、账号隔离持久化、落盘后 ack、前台轮询与退避、历史及已读。统一 VERSION 同时管理该包。

## uniapp-client

- 补齐单聊、会话/历史分页、阅读回执、独立未读、设备 token 和推送偏好。
- 增加短期 ticket WebSocket、串行落盘后确认、有界帧队列、断线补拉和前后台暂停恢复。
- 导出 HttpApi、SyncClient、NotificationSender、RetryPolicy 和领域校验；提供 HTTP/Socket/存储/codec/凭证端口。并发鉴权刷新、有限瞬时错误重试、请求体冻结、中止和资源所有权覆盖默认适配器。
- 去掉通知缓存 500 条静默截断；明确 uni 存储配额失败不 ack、平台 UI/APNs 与可信 Outbox 的边界。
- 增加 npm tgz 独立安装与真实 HTTP/WS 验收，接入跨语言集成 CI；统一补充当前功能和技术设计文档。
