# Polyglot IM 0.1.1

## 项目与构建

- 压测支持完整矩阵报告与单/四进程发压诊断，分别核验服务源码、原始样本和资源预算；WS 超时保存失败计数并继续后续轮次，保留预热与连接错误；修正已退出进程组的权限探测误报。

- 长时间压测每轮完成后原子保存结果，支持 .json.gz 输出与报告读取；中断时保留已完成轮次，以实际覆盖区分完整矩阵和部分测量。

- 完成七场景、单/双实例、四档并发、三轮重复共 168 轮压测，保留 32 条 WS 未确认投递及共享主机干扰；补充写入与历史读取的 12 轮发压进程诊断。README 展开全部 56 个测试单元的结论，逐轮详情、数据库 CPU/I/O/WAL 与等待、原始数据及异常日志可复核。测量服务基线为 0.1.0 对应历史源码，不宣称已测得后续业务版本容量。

- 新增本机 Scala Client 发布入口，统一版本 0.1.1；远程发布继续禁止。

## scala-client

- 提供固定版本本地 Ivy 依赖，验证作者审核消息共享契约。

## scala-server

- 支持 open_user / open_review 受控动作及 APNs 通知分组。

## dart-client

- 提供显式停止前台兜底轮询，增加审核消息往返契约。

## flutter-client

- 前台系统通知按账号显式配置；消息卡片支持关闭点击累计已读，后台停止轮询。

## python-client

- 增加审核消息共享契约，未知 payload 向前兼容。

## benchmark

- 无行为变更，使用统一版本。

## 用户会话与 uni-app

- Server 提供 UserAuthenticator 用户鉴权端口及默认固定 HTTP 内省适配器，启用后关闭本地用户 JWT，生产者权限仍独立校验。
- 增加 uni-app 本地 npm 包，默认 uni.request、账号隔离持久化、落盘后 ack、前台轮询与退避、历史及已读。统一 VERSION 同时管理该包。
