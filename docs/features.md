# 常见消息功能与状态矩阵

## 状态说明

**已实现**：仓库有可执行代码与对应验证。**规划**：本文件规定目标行为，尚不可在 SDK 中调用。M0 初始化；M1 可靠通知；M2 实时与多端；M3 单聊与群聊；M4 高级消息及治理。阶段按依赖推进，不是日期承诺。

## 初始化能力

| 功能 | 状态 | 验收依据 |
| --- | --- | --- |
| 三语言消息信封编解码 | 已实现 M0 | 同一 JSON 样例往返，大序号不丢精度 |
| Schema、当前 OpenAPI、中文文档检查 | 已实现 M0 | just check-docs |
| Flutter 生命周期恢复回调 | 已实现 M0 | 重复挂载不重复订阅，释放后不回调 |
| Scala 存活/就绪探针 | 已实现 M0 | live=200、ready=503、未知路由=404 |
| just 构建、检查与 GitHub CI | 已实现 M0 | 以验证记录及 GitHub 实际结果为准 |

## 会话与消息

| 功能 | 状态 | 核心语义与验收条件 |
| --- | --- | --- |
| 业务通知、系统会话 | 规划 M1 | 服务身份发送；业务幂等；不允许用户伪造系统作者 |
| 单聊与会话唯一性 | 规划 M3 | 同一对用户重复创建返回同一会话 |
| 群聊、群详情与成员分页 | 规划 M3 | 每次读取和写入验证成员及可见范围 |
| 文本、Unicode、Emoji | 规划 M1 | 中文、换行与组合字符完整往返；长度按公开规则校验 |
| 自定义/业务卡片消息 | 规划 M1 | 类型命名空间、未知类型回退；无任意脚本执行 |
| 图片与相册消息 | 规划 M3 | 多图排序、尺寸、缩略图、鉴权与失败占位 |
| 语音 | 规划 M3 | 时长、格式、下载权限；播放状态默认本地 |
| 视频 | 规划 M3 | 封面、时长、大小；不经 WS 传文件 |
| 文件 | 规划 M3 | 文件名、大小、MIME、扫描状态、过期状态 |
| 位置、名片、链接卡片 | 规划 M4 | 明确坐标系；URL 预览防 SSRF；个人资料权限校验 |
| Markdown / 富文本 | 规划 M4 | 安全渲染、链接确认、禁止原始脚本与危险 HTML |
| 回复与引用 | 规划 M3 | 跨权限引用被拒绝；撤回后引用显示占位 |
| 单条/合并转发 | 规划 M4 | 新消息身份；原附件权限和私密字段重新校验 |
| @成员、@全体 | 规划 M3 | @身份结构化；@全体受角色与频率限制 |
| 表情回应、撤销回应 | 规划 M4 | 用户+消息+表情唯一；重复操作不重复计数 |
| 编辑及编辑标记 | 规划 M4 | 乐观版本校验；保留编辑状态与审计 |
| 撤回与管理员撤回 | 规划 M3 | 时间窗与角色控制；多端墓碑，不宣称远程擦除 |
| 消息定时发送、TTL | 规划 M4 | 到期前可取消；重复调度幂等；过期同步墓碑 |
| 消息收藏、固定、稍后处理 | 规划 M4 | 收藏属用户；群固定消息受角色控制 |

## 可靠性与多端

| 功能 | 状态 | 核心语义与验收条件 |
| --- | --- | --- |
| 服务端持久化与 Outbox | 规划 M1 | 事务回滚不产生通知；提交后 Worker 重启可恢复 |
| 发送队列、超时与失败重试 | 规划 M1 | 同一发送意图复用幂等键；同键不同内容冲突 |
| HTTP 历史分页 | 规划 M1 | 稳定 before_seq；新写入不导致翻页重复或遗漏 |
| 增量同步与游标过期恢复 | 规划 M1 | 短断网补拉；长断网快照追增量；撤回不复活 |
| WebSocket、心跳、重连、背压 | 规划 M2 | 弱网与慢消费者下有界；无静默丢事件 |
| 发送、送达、已读状态 | 规划 M2 | 区分提交、设备落盘和用户阅读 |
| 私聊已读与群回执 | 规划 M2/M3 | 私聊用户水位；群按需分页查看，避免全量广播 |
| 多设备、账号切换、设备踢出 | 规划 M2 | 缓存隔离、迟到回调隔离、旧 token 撤销 |
| 消息去重与会话顺序 | 规划 M1 | 重复事件一次生效；顺序不依赖客户端时间 |
| 在线、最后活跃、正在输入 | 规划 M3 | 租约过期、节流、可见性与隐私设置 |
| 浏览器多标签与存储降级 | 规划 M2 | 标签协调；存储不可用时明确告知离线能力下降 |

## 会话管理、提醒与检索

| 功能 | 状态 | 核心语义与验收条件 |
| --- | --- | --- |
| 未读、红点、清零、标记未读 | 规划 M1/M4 | 持久已读水位与“稍后处理”标志分开 |
| 置顶、排序、归档 | 规划 M3 | 用户级偏好；新消息是否解除归档可配置 |
| 草稿 | 规划 M3 | 本地按会话保存；跨端草稿为 M4 可选能力 |
| 免打扰、静音、分时段提醒 | 规划 M2 | 含时区与夏令时策略；@提醒例外可配置 |
| 删除消息、删除/清空会话 | 规划 M3 | 本设备、用户所有设备和合规删除明确区分 |
| 本地/服务端全文搜索 | 规划 M4 | 权限一致；中文索引验证；撤回与退群后不可搜索 |
| 媒体/文件分类检索 | 规划 M4 | 同会话可见性；资源过期有明确结果 |
| 推送 token 注册/轮换/失效 | 规划 M2 | 退出解绑；token 不记录在普通日志 |
| APNs、FCM、厂商通道 | 规划 M2 | 各平台真机验证；不能由通道接受推断已送达 |
| 推送点击、冷启动、角标 | 规划 M2 | 登录后导航、补拉、去重；切账号不打开他人资源 |
| Web / 桌面系统通知 | 规划 M4 | 按平台能力声明；权限拒绝不影响站内消息 |

## 群管理、开放能力与治理

| 功能 | 状态 | 核心语义与验收条件 |
| --- | --- | --- |
| 建群、解散、退群、移除成员 | 规划 M3 | 操作幂等；退出与发消息并发时权限一致 |
| 群主、管理员、成员与转让 | 规划 M3 | 角色矩阵；群主不能直接离开而留下无主群 |
| 邀请、入群申请与审批 | 规划 M3 | 邀请有效期、防重复、权限和审计 |
| 群公告、群昵称、资料变更 | 规划 M3 | 管理权限；变更产生规范系统事件 |
| 全群/单成员禁言、发送限制 | 规划 M3 | 服务端强制；前端禁用按钮不足以验收 |
| 新成员历史可见范围 | 规划 M3 | joined_seq/历史策略；附件、搜索同样受限 |
| 拉黑、陌生人私信与举报 | 规划 M3/M4 | 用户关系由业务适配；授权决策在写入前执行 |
| 文本与媒体审核 | 规划 M4 | 隔离/拒绝/人工审核策略；失败重试不绕过审核 |
| 机器人和服务身份 | 规划 M1/M4 | 最小作用域；机器人不持有用户管理凭证 |
| Webhook 订阅 | 规划 M4 | HMAC、时间窗、防重放、重试、死信、人工重放 |
| 审计、留存、导出与删除 | 规划 M4 | 应用级政策、合法授权、备份过期与审计一致 |
| 大群、广播与限额 | 规划 M4 | 群规模明确；混合扇出、限流、背压经过压测 |
| 实时音视频、屏幕共享 | 独立扩展 | 需额外 RTC 服务、信令与媒体架构 |
| 端到端加密 E2EE | 独立扩展 | 需密钥、多端与恢复设计；TLS 不等于 E2EE |

## 完成标准

功能只有在服务端授权、持久化、三端协议兼容、失败恢复、文档及对应验收通过后才可标记完成。平台推送额外要求真机与权限拒绝场景证据。“所有常见消息功能”是本矩阵的设计覆盖范围，不是初始化版本已全部实现的声明。
