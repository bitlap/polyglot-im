# 常见消息功能与状态矩阵

## 状态说明

**已实现**：仓库有可执行代码与对应验证。**规划**：本文件规定目标行为，尚不可在 SDK 中调用。M0 初始化；P0/M1 App 站内消息闭环；P1/M2 实时与后台提醒；P2/M3 单聊与通用增强；P3/M4 群聊、撤回与高级能力。阶段按依赖推进，不是日期承诺。优先级与实际执行顺序见[实施路线](roadmap.md)。

App 第一版优先交付通知发送/接收、消息列表、未读/已读、缓存、账号隔离和可靠补拉；后台推送与前台实时更新紧随其后。群聊和撤回不作为 App 基础版本的前置条件。

## 完成标准

功能只有在服务端授权、持久化、三端协议兼容、失败恢复、文档及对应验收通过后才可标记完成。平台推送额外要求真机与权限拒绝场景证据。“所有常见消息功能”是本矩阵的设计覆盖范围，不是初始化版本已全部实现的声明。
